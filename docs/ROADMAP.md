# Roadmap

- Stack profiles for TypeScript, .NET, Java, Python, Go, Rust, Flutter and native mobile.
- Architecture lint rules for common monorepo dependency tools.
- JSON architecture report schema for CI/agent interoperability.
- More product profiles: DMS, accounting, POS, collaboration, IoT and AI-agent platforms.
- Evals that measure architecture recommendation stability and over-engineering rate.
- Optional diagram generation (Mermaid/C4) from the same decision model.
